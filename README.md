## `03 / MALWARE ANALYSIS & THREAT RESEARCH`

<sub>STATIC ANALYSIS • DYNAMIC ANALYSIS • INDICATORS OF COMPROMISE</sub>

- **Static analysis:** inspect file metadata, hashes, strings, imports, and suspicious artifacts without executing the sample.
- **Dynamic analysis:** observe process, file, registry, and network behavior in an isolated sandbox.
- **IOC extraction:** identify useful hashes, domains, IPs, paths, and other investigation indicators.
- **Behavioral analysis:** record execution flow, persistence attempts, and suspicious system interactions.
- **Threat research:** connect observed behavior with known techniques and document evidence.
- **Reporting:** summarize behavior, risk, indicators, and defensive recommendations.
