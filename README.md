# Gustav Nurhidayat

Security enthusiast working on both sides of the fence: web app pentesting and recon on the offensive side, SOC work and malware analysis on the defensive side.

I like understanding how something breaks, and then what evidence that break leaves in the logs.

## What I work on

**Offensive**
- Web app testing against the OWASP Top 10: auth, access control, injection, XSS, misconfigurations
- Recon and attack-surface mapping: subdomains, endpoints, parameters, exposed content
- Writing up findings with evidence, impact, and a fix

**Defensive**
- Alert triage and log analysis in a SIEM
- Building investigation timelines and mapping activity to MITRE ATT&CK
- Telling real incidents from noise, and suggesting detection improvements

**Malware analysis**
- Static analysis (hashes, strings, imports) and dynamic analysis in an isolated sandbox
- Extracting IOCs and documenting behavior

## Tools I use

- **Offensive:** Burp Suite, Nmap, ffuf, Subfinder, Katana, OWASP ZAP
- **Defensive:** Splunk, Wazuh, Elastic, Sysmon, Wireshark
- **Malware:** DiE, YARA, Ghidra, REMnux
- **General:** Linux (Kali), Python, Bash, Docker, Git
